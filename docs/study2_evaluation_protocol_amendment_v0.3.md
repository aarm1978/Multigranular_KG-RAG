## 3. Predeclared agreement reporting

Use the full 182 paired initial candidate-support judgments, matched by opaque ID.
Report exact observed agreement and three-category nominal Cohen's kappa overall,
for nodes (133), and for relations (49). Include each 3-by-3 category confusion/count
table and marginal counts. Retain insufficient-evidence judgments as the third
category. Target-level agreement is descriptive only where support is adequate,
with item/category counts disclosed; no target-level inferential claim is authorized.
The formulas, undefined-kappa handling, and incomplete-review handling are specified
in Step 5 v0.1.4 Section 3. Reconciled outcomes do not enter this initial agreement
calculation. This is not extraction IAA and does not replace Human Core reliability.
